# SHPH Queue · ระบบเรียกคิว รพ.สต.

ระบบเรียกคิวคนไข้แบบเบาๆ สำหรับโรงพยาบาลส่งเสริมสุขภาพตำบล ใช้ PC เครื่องเดียวเป็นเครื่องแม่ข่าย ส่วนเครื่องอื่นในวง LAN (ห้องตรวจ ห้องยา จอทีวี) แค่เปิดเบราว์เซอร์มาที่เครื่องนี้

- โปรแกรมเป็น **ไฟล์ `.exe` ไฟล์เดียว** ไม่ต้องติดตั้ง Python, Node หรือฐานข้อมูลแยก
- ข้อมูลเก็บใน SQLite ไฟล์เดียว (`data/queue.db`) ปิดโปรแกรมแล้วเปิดใหม่ คิวก็ต่อจากเดิม
- ทุกจอเปลี่ยนตามกันทันทีผ่าน WebSocket
- เขียนด้วย Rust (Axum + SQLite) ส่วนหน้าเว็บเป็น HTML/CSS/JS ธรรมดา ฝังอยู่ใน `.exe`

## หน้าเว็บ

| ที่อยู่ | ใช้ที่ | ทำอะไร |
|---|---|---|
| `/display` | ทีวีให้คนไข้ดู | เลขคิวแต่ละห้อง ป้ายเรียกคิว เสียงประกาศภาษาไทย คิวถัดไป คิวที่เรียกแล้วไม่มา สื่อประชาสัมพันธ์ (YouTube, วิดีโอ, รูป) และข้อความวิ่ง |
| `/room/{id}` | PC ในห้องตรวจ / ห้องยา | เรียกคิวถัดไป เรียกซ้ำ ไม่มา·พักคิว เสร็จ·ส่งห้องยา เสร็จ·ไม่รับยา เรียกหมายเลขที่ระบุ เรียกกลับจากพักคิว และย้อนกลับเมื่อกดผิด |
| `/manage` | เครื่องเจ้าหน้าที่ | ควบคุมทุกห้องจากหน้าเดียว จัดการพักคิวและคิวรอรับยา ตั้งเลขล่าสุด เริ่มคิวใหม่ และดูบันทึกการทำงานวันนี้ |
| `/admin` | ผู้ดูแลระบบ (มีรหัสผ่าน) | ตั้งค่าห้อง เลขคิว เสียง จอแสดงผล และสื่อ ดูสถิติวันนี้ ดูอุปกรณ์ที่เชื่อมต่อ สำรองข้อมูล |

### การทำงานของคิว

- **ใช้บัตรคิวกระดาษ**: ระบบมีตัวนับกลางตัวเดียว ห้องตรวจไหนว่างก็กด "เรียกคิวถัดไป" แล้วได้เลขถัดไป ถึงเลขสุดท้าย (ค่าเริ่มต้น 99) ก็วนกลับไปเลขแรก
- **ห้องยา (เปิด/ปิดได้)**: ห้องตรวจกด "เสร็จ · ส่งห้องยา" แล้วเลขจะเข้าคิวรอรับยา ห้องยาเรียกต่อจากคิวนี้ ถ้าไม่ต้องรับยาให้กด "เสร็จ · ไม่รับยา"
- **พักคิว**: กด "ไม่มา" แล้วเลขจะขึ้นบนจอในช่อง "เรียกแล้วไม่พบ" (หน้าละ 5 เลข เกินนั้นจอพลิกหน้าเอง) และระบบเอาออกเองเมื่อพักเกินเวลาที่ตั้งไว้ (ค่าเริ่มต้น 60 นาที)
- **ย้อนกลับ**: แต่ละห้องย้อนการกดของตัวเองได้ 10 ครั้งล่าสุด
- **เริ่มคิวใหม่อัตโนมัติ** เมื่อขึ้นวันใหม่

## ติดตั้งบน Windows

1. ดาวน์โหลด `SHPH-Queue-windows` จากแท็บ **Actions** (build ล่าสุด) หรือจากหน้า **Releases**
2. แตกไฟล์ไว้ เช่น `C:\SHPH-Queue` แล้วดับเบิลคลิก `shph-queue.exe`
3. Windows ถาม Firewall ให้อนุญาต **Private networks**
4. หน้าต่างโปรแกรมจะแสดงที่อยู่ เช่น `http://192.168.1.10:8000` นำไปเปิดที่เครื่องอื่น
5. เข้า `/admin` (รหัสผ่านเริ่มต้น `admin`) แล้ว**เปลี่ยนรหัสผ่าน** ตั้งชื่อ รพ.สต. และตั้งเลขคิวให้ตรงกับบัตรกระดาษ

คำแนะนำเพิ่มเติม:
- ตั้ง IP ของเครื่องแม่ข่ายให้คงที่ ไม่อย่างนั้นที่อยู่จะเปลี่ยนเมื่อรีสตาร์ต
- `install-autostart.bat` ทำให้โปรแกรมเปิดเองเมื่อเปิดเครื่อง
- ถ้าเครื่องอื่นเข้าไม่ได้ ให้คลิกขวา `open-firewall.bat` แล้วเลือก Run as administrator
- เปลี่ยนพอร์ตได้ด้วย `shph-queue.exe --port 8080`

### จอทีวี Google TV

Google TV ไม่มี Chrome มาให้ แนะนำให้ติดตั้ง **Fully Kiosk Browser** แล้วตั้งค่าดังนี้:
- Start URL: `http://<IP เครื่องแม่ข่าย>:8000/display`
- Web Content Settings → เปิด *Autoplay Videos* และ *Autoplay Audio*
- เปิด *Keep Screen On* และ *Launch on Boot*

ถ้าเบราว์เซอร์ไม่ยอมเล่นเสียงเอง จอจะขึ้นแถบให้แตะหน้าจอหรือกดปุ่ม OK ที่รีโมต 1 ครั้ง ทดสอบได้จาก `/admin` → ทดสอบเสียง

## เสียงประกาศ

ตัวอย่างประโยค: "ขอเชิญหมายเลข **สิบสอง** ที่ห้องตรวจ **สอง** ค่ะ" ระบบอ่านตัวเลขเป็นคำไทย เช่น 11 = สิบเอ็ด, 21 = ยี่สิบเอ็ด, 101 = หนึ่งร้อยเอ็ด

ระบบสร้างเสียงจากไฟล์เสียงสั้นๆ หลายท่อนมาต่อกัน (รายการไฟล์อยู่ใน `voice/voice_lines.json`):
- `invite` "ขอเชิญหมายเลข", `num_1` … `num_99`, `hundred_1` … `hundred_9`, `ed` "เอ็ด"
- `phrase_exam` "ที่ห้องตรวจ", `phrase_pharmacy` "รับยาที่ห้องยา" และวลีอื่น
- `end` "ค่ะ"
- `room_{id}` (ไม่บังคับ) ใช้แทนเสียงชื่อห้องทั้งท่อน

แหล่งไฟล์เสียง:
1. **Build จาก GitHub Actions** จะสร้างไฟล์เสียงผู้หญิง (`th-TH-PremwadeeNeural`) ใส่โฟลเดอร์ `voice/` ให้ โดยใช้ `tools/make_voice.py` ซึ่งเรียกเสียงออนไลน์ของ Microsoft Edge ผ่านแพ็กเกจ `edge-tts` (ไม่ใช่ API ทางการ)
2. **สร้างเอง** บนเครื่องที่มีอินเทอร์เน็ต: `pip install edge-tts` แล้วรัน `python tools/make_voice.py`
3. **อัดเสียงเจ้าหน้าที่เอง** ตั้งชื่อไฟล์ตามรายการ แล้วอัปโหลดในหน้า `/admin` → ไฟล์เสียง

ถ้าไฟล์เสียงไม่ครบ จอจะใช้เสียงอ่านภาษาไทยของเบราว์เซอร์แทน (ถ้าเครื่องนั้นมีเสียงไทย) และถ้าไม่มีก็จะได้ยินแค่เสียงกริ่ง

## สำรองและกู้คืนข้อมูล

- `/admin` → ดาวน์โหลดไฟล์สำรองข้อมูล ได้ไฟล์ `.db`
- กู้คืน: ปิดโปรแกรม แล้วนำไฟล์ไปวางแทน `data\queue.db`

## พัฒนาต่อ

```bash
cargo run -- --dir ./dev-data          # http://localhost:8000
cargo test                             # ทดสอบตรรกะคิวและการอ่านตัวเลข
cargo build --release                  # target/release/shph-queue(.exe)
```

โครงสร้างโปรเจกต์:

```
src/
  main.rs     เส้นทาง URL, WebSocket, งานเบื้องหลัง (เริ่มวันใหม่, ล้างพักคิว)
  app.rs      สถานะกลาง, บันทึกลงฐานข้อมูล, สร้างข้อความประกาศ
  queue.rs    ตรรกะคิวทั้งหมด + ย้อนกลับ + unit tests
  api.rs      HTTP API, ล็อกอินผู้ดูแล, อัปโหลดไฟล์
  db.rs       SQLite
  model.rs    โครงสร้างข้อมูลและค่าตั้งต้น
  thai.rs     อ่านตัวเลขเป็นคำไทย
web/          หน้าเว็บทั้งหมด (ฝังเข้าไปใน .exe ตอน build)
voice/        รายการไฟล์เสียง + ไฟล์เสียง (ไม่เก็บใน git)
tools/        สคริปต์สร้างไฟล์เสียง
packaging/    ไฟล์ .bat และคู่มือสำหรับชุดติดตั้ง Windows
```
